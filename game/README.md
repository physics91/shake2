# 쉐이크2 복원판 (웹)

2002년 아오조라 엔터테인먼트 「쉐이크2」의 원본 그래픽·효과음·배경음으로 만든 브라우저 재구현입니다.
원본 에셋은 저작권이 있으므로 개인 보존·연구용으로만 쓰고 `public/assets/`를 재배포하지 마세요.
0311판에 그림이 없는 내 정보 화면과 그 옵션 쪽은 같은 회사의 「쉐이크1」 그림(`status.shk`, `option.shk`)을 `shakefmt.export`가 함께 뽑아 씁니다. 이것도 재배포하지 마세요.

## 준비

Node 24 이상이 필요합니다(서버가 TypeScript를 빌드 없이 직접 실행).

```bash
cd ../tools && python3 -m shakefmt.export   # 원본 그래픽·효과음·맵 → assets/extracted/
python3 -m shakefmt.dmreverb                 # 합성기 리버브 실측 → assets/extracted/dmsynth/reverb.npz (선택, Windows)
python3 -m shakefmt.bgm                      # 원본 MIDI → assets/extracted/bgm/*.flac (선택)
python3 -m shakefmt.font                     # Windows gulim.ttc의 비트맵 글자 → assets/extracted/font/ (선택)
cd ../game && npm install && npm run sync-assets   # → public/assets/ + manifest.json
```

배경음 렌더링에는 Windows의 `gm.dls`(자동 탐색, 또는 `--dls` / `SHAKE2_GM_DLS`)와 `ffmpeg`가 필요합니다.
`gm.dls`와 렌더링한 오디오는 재배포할 수 없습니다. 이 단계를 건너뛰면 배경음 없이 실행됩니다.
원본 합성기는 리버브가 기본으로 켜져 있습니다. `shakefmt.dmreverb`가 Windows Python(`py.exe -3`, 또는 `SHAKE2_WINDOWS_PYTHON`)으로
이 PC의 DirectMusic 합성기를 소리 없이 재고, `shakefmt.bgm`이 그 응답을 걸어 렌더합니다. 측정값이 없으면 리버브 없이 렌더합니다(`--no-reverb`로도 끔).
측정값도 재배포하지 않습니다.
배경음은 원본 합성기처럼 한 음이 풀스케일까지 닿는 크기로 정규화 없이 렌더하므로, 게임 곡 대부분이 원본처럼 군데군데 잘립니다(클리핑).
반복은 DirectMusic처럼 마지막 이벤트가 든 마디의 끝에서 시작합니다.
원본 글자는 GDI가 `gulim.ttc`의 내장 비트맵(굴림체 12·13·14, 굴림 15)을 찍은 것입니다. `shakefmt.font`가 이 PC의 글꼴(자동 탐색, 또는 `--ttc` / `SHAKE2_GULIM_TTC`)에서
그 비트맵을 뽑으면 캔버스 글자가 원본과 픽셀 단위로 같아집니다. 뽑은 글꼴 데이터도 재배포할 수 없습니다. 건너뛰면 브라우저 글꼴로 비슷하게 그립니다.
캐릭터 색조는 원본처럼 `.spr`의 8비트 색을 16비트로 자르기 전에 돌리므로, `shakefmt.export`가 캐릭터 시트의 8비트 색을 `<이름>.rgb.png`로도 뽑습니다.
이 파일이 없는 예전 추출본이면 색조 없이 그립니다(내보내기와 `sync-assets`를 다시 돌리면 됩니다).
개발 서버를 띄운 채 `sync-assets`를 다시 돌렸다면 개발 서버를 다시 시작하세요(자산 폴더를 새로 만들어 서버가 놓칩니다).

## 실행

| 목적 | 명령 |
|---|---|
| 개발 서버 | `npm run dev` → http://localhost:5173 (`#/`는 원본 시작 흐름, 에셋 뷰어는 `#/viewer`로 직접 열기) |
| 온라인 대전 서버 | `npm run server` (기본 `127.0.0.1:8787`, 페이지는 같은 주소의 `/ws`로 프록시) |
| 배포용 빌드 확인 | `npm run build && npm run preview` (+ `npm run server`) |
| 검사 | `npm test && npm run typecheck` |

서버 환경 변수: `HOST`(LAN 대전은 `0.0.0.0`), `PORT`, `ALLOWED_ORIGINS`(쉼표 구분 추가 허용 Origin), `MAX_ROOMS`(채널마다), `MAX_USERS`(채널마다 정원, 기본 200),
`CHANNELS`(서버 목록 줄: `이름|#rrggbb|최고-최저 레벨`을 쉼표로, 색과 레벨은 생략 가능. 예 `루키코벱|#ff8080|11-12,자유코벱|#80ff80`) 또는 `CHANNEL`(줄 하나의 이름, 기본 흰 "복원판 채널"),
`ACCOUNTS_FILE`(계정 파일, 기본 `data/accounts.json`), `DEFAULT_ITEMS`·`DEFAULT_PAIRS`(새 계정이 가질 아이템 칸과 캐릭터 쌍, 기본 12(모든 아이템)와 0~9), `FRIENDS_FILE`(친구 목록 파일, 기본 `data/friends.json`),
`TLS_CERT`·`TLS_KEY`(PEM 파일 경로, 둘 다 주면 `wss://`, 하나만 주면 시작하지 않음), `TRUST_PROXY`(쉼표 구분, `X-Forwarded-For`를 믿을 프록시의 IP 주소. 호스트 이름은 안 되고 루프백은 늘 믿음).
TLS 없이 `127.0.0.1`·`localhost` 밖에서 듣게 하면 시작할 때 계정·방 암호가 평문으로 간다는 경고를 한 줄 찍습니다.
개발·미리보기 서버의 `/ws` 프록시는 브라우저 주소를 `X-Forwarded-For`에 덧붙여 넘깁니다. 서버 앞에 다른 프록시를 두면 그 주소를 `TRUST_PROXY`에 넣어야 사람마다 따로 셉니다. 받은 헤더를 그대로 넘기기만 하는 프록시는 넣지 마세요(접속자가 제 주소를 골라 씀). 같은 기계의 프로그램은 루프백이라 늘 믿으므로 헤더로 주소를 고를 수 있습니다.
클라이언트와 서버는 같은 프로토콜 번호(지금 14: 7에서 친구 목록을 서버가 둠, 8에서 채팅 명령어, 9에서 패널 막대, 10에서 비밀방, 11에서 계정, 12에서 계정 휘장과 사용자 정보, 13에서 길드 고르기, 14에서 랭킹)를 써야 접속됩니다. 게임 서버에 접속할 때 버전이 다르면 원본 문구("버전이 업데이트 되었습니다")를 띄우고 페이지를 다시 읽습니다. 코드를 새로 받았으면 서버도 다시 시작하세요.

계정 파일에는 아이디, 닉네임, 비밀번호의 scrypt 해시(계정마다 소금), 인사말, 캐릭터·색조, 길드, 전적·셀포인트·캔디, 아이템과 캐릭터 쌍이 들어갑니다. 비밀번호 자체는 어디에도 저장하지 않지만 해시도 추측 공격의 재료가 되므로 파일은 서버 계정만 읽도록(0600) 쓰고, 공개하거나 배포하지 마세요. 읽지 못하는 파일은 `accounts.json.broken-<시각>`으로 옮긴 뒤 빈 채로 시작합니다.
계정은 로그인 화면의 NEW ID(가입 창)로 만듭니다. 원본 가입 창에는 실명·주민등록번호·지역·이메일 칸이 있지만 복원판은 받지 않아 그 칸은 비어 있고, 약관 자리에는 서버가 저장하는 것을 알리는 글이 있습니다(주민등록번호는 법령 근거 없이 처리할 수 없음). 비밀번호는 원본 편집기대로 4~10바이트라 짧습니다. 서버는 로그인을 주소마다 하나씩 확인하고 틀릴 때마다 다음 확인을 0.5초부터 30초까지 늦추며, 가입은 주소마다 10초에 한 번만 받습니다.
로비에 있는 사람에게는 로비 사용자 모두의 아이디·닉네임·인사말·전적·셀포인트·순위·레벨·길드가 가고(사용자 정보 창), 방·경기·결과 화면에는 아이디 체크에 따라 아이디나 닉네임과 길드·레벨 휘장이 나옵니다. 레벨은 순위로 정합니다(한판더넷 표: 1위, 8위, 85위까지, 그 뒤 상위 백분율, 전적이 없으면 루키).
경기가 끝나 결과 화면이 뜨면 서버가 원본 클라이언트의 식(방장 PC가 계산하던 셀 몫)으로 각자의 셀포인트 몫을 계정에 더하고, 이긴 사람은 승, 나머지는 패, 주운 캔디를 셉니다. 결과 화면 전에 방을 나가거나 끊기면 한판더넷 규칙대로 셀 −200과 패 하나입니다. 원본처럼 셀포인트·전적·레벨·순위는 로그인 때만 받으므로 바뀐 값은 다음 로그인(채널에 다시 들어갈 때 포함)부터 보입니다.
랭킹은 한 판이라도 끝낸 계정을 셀포인트 순으로 15줄씩 보이며, 로그인한 사람에게만 답합니다(원본 랭킹 서버는 누구에게나 열려 있었고 하루 한 번 갱신). 서버는 물을 때마다 순위를 다시 셉니다.
로그인하면 서버가 메모리에만 두는 세션 토큰을 주고, 게임 서버(채널)에 들어갈 때 그 토큰을 씁니다. 같은 계정으로 다시 로그인하면 이전 토큰은 무효이고, 같은 계정이 이미 채널에 있으면 "이미 로그인 되어 있습니다"로 거절합니다. 서버를 다시 시작하면 모두 다시 로그인해야 합니다.
인증 서버에 닿지 않으면 로그인 위에 "인증서버 접속 실패"가 뜨고, 그대로 OK를 누르면 계정 없이 내 정보 화면으로 가서 연습과 2인 대전만 할 수 있습니다(메시지 상자를 OK나 Esc로 닫으면 다시 접속합니다).

친구 목록 파일에는 로그인 아이디와 각 아이디의 친구 아이디가 들어갑니다. 친구 목록은 친구의 길드·레벨을 보이고, 위치는 같은 채널이면 로비(채널 이름)나 방 번호, 다른 채널이면 그 채널 이름입니다. 파일은 서버 계정만 읽도록(0600) 쓰고, 읽지 못하는 파일은 `friends.json.broken-<시각>`으로 옮긴 뒤 빈 목록으로 시작합니다. 이 파일은 공개하거나 배포하지 마세요. 서버는 아이디를 4096개까지 기억하며, 목록에 없는 오래된 아이디부터 잊습니다.

조작은 원본과 같이 방향키, Space(폭탄), 왼쪽 Ctrl(공격용: 직격탄·시한폭탄 기폭), Z(회피용: 점프·땅굴·순간이동)가 기본이고, 로비 리모컨의 옵션 창에서 세 키와 조이스틱(게임패드)을 바꿀 수 있습니다. 브라우저는 페이지에서 패드 단추를 한 번 눌러야 패드를 보여 주므로, 조이스틱으로 두어도 그 전까지는 키보드로 움직입니다. 2인 한 키보드 모드는 복원판에서 추가한 기능으로, 서버 목록의 둘째 줄 "2인 대전"을 두 번 누르면 원본 대기실 화면으로 들어가며 1P는 WASD·Space·Q·E, 2P는 방향키·Enter·오른쪽 Ctrl·쉼표를 씁니다.

## 구조

- `src/sim/` — DOM 없는 결정적 게임 규칙(원본과 같은 30 Hz 고정 틱). 클라이언트와 서버가 함께 씀
- `src/client/` — Canvas 렌더러, 화면 좌표(`hudLayout.ts`), 키보드, 효과음·배경음, 메뉴, 에셋 뷰어, 온라인 로비
- `src/server/` — 방 서버(`ws`). 서버가 규칙을 진행하고 매 틱(30 Hz) 상태를 보냄

## 원본과의 일치 정도

규칙 수치, 이동·충돌, 그리기 순서와 화면 좌표, 효과음·배경음 배정은 원본 `shake.exe`를 분석해 옮겼습니다.
항목별 근거 주소와 남은 추정(I)·재구성(R)은 [`original/FIDELITY.md`](../original/FIDELITY.md)에 있습니다.

특수 아이템(개인전 숨은 아이템 전체: 특수 폭탄, 차기·손·스페셜, 점프·땅굴·순간이동, 알 보호막, 저주, 폭탄 스위치)과
오브젝트 맵(워프, 방향·보는 방향 점프대, 폭발증폭, 제너레이터, 동시폭발지역)은 구현했고, 방 맵 16개를 모두 고를 수 있습니다.
혼자 연습은 내 정보 화면의 Practice로 들어가는 원본 장면 9를 따릅니다(시간이 다 되면 내 정보 화면으로 돌아옴): 허수아비 3명, 연습 전용 아이템(지뢰탄·호박탄·물/똥/사과/팬더탄과 실명 화면),
끝 상자와 Esc 상자, F1 도움말, textbox 도움말, Enter 채팅(말풍선 5초, 서버로 보내지 않음).
온라인 방에서는 원본의 게임 방식 8가지(개인전, 자유/매너 팀 매치, 화력 개인전·팀매치, 소환 팀매치)를 고르고 팀(6색)을 나눌 수 있습니다.
같은 편에게도 폭탄이 맞고, 소환 모드는 죽은 자리에 캡슐이 떨어져 주운 사람 팀의 죽은 사람이 되살아납니다.
대기실은 원본 "GAME ROOM" 화면을 원본 그림과 좌표로 그립니다: 슬롯 열기·닫기, 맵·음악·게임 방식 ◀▶와 끌어서 고르는 목록,
맵 미리보기, SELECTTEAM, START 깜박임, 방 채팅(45바이트, 2초 간격, 입장·퇴장 줄, 7줄 기록과 스크롤), 풍선 도움말, F1 도움말 화면, EXIT 상자.
로비도 원본 "LOBBY" 화면입니다: 방 목록(쪽 넘김, WAIT GAME), 로비 사용자, 로비 채팅과 스크롤, 방 만들기 창, 오른쪽 버튼 방 정보 창,
메시지 상자, 리모컨(채널변경은 서버 목록으로), 풍선 도움말, F1 도움말 화면. 채널 이름과 색은 서버의 `CHANNELS` 환경 변수로 정합니다.
방 만들기 창의 자물쇠 아이콘으로 비밀방을 만들 수 있습니다(상점이 없어 아이템 5를 모두 가진 것으로 봄). 비밀방 줄은 잠긴 문 아이콘이고, 누르거나 `/go`·방 코드로 들어가면 원본 암호 창이 뜹니다(프로토콜 10).
암호는 서버에만 두고 다른 사람에게 보내지 않지만 `ws://`로는 평문으로 가므로, 인터넷에 서버를 열 때는 `TLS_CERT`·`TLS_KEY`로 `wss://`를 켜거나 TLS 프록시 뒤에 두세요(https 페이지는 `wss://`로 붙음).
