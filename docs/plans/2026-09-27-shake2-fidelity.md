# 쉐이크2 복원: 원본 재현도 올리기

## Goal

효과음, 그래픽, 조작, 규칙을 2002년 원본(`Shake0311`, `shake.exe` 2002-02-28 빌드)과 같게 만든다.
추정값은 원본 근거(바이너리 코드, 당시 문서·스크린샷, 원본 데이터)로 하나씩 대체하고, 근거와 남은 추정을 표로 남긴다.

## Scope

- 효과음: 상황별 WAV 배정, 반복/중단 규칙을 `shake.exe` 코드에서 확인해 그대로 적용
- 배경음: `bgm/*.mid` 14곡과 대기 음악 2곡을 로컬 `gm.dls`로 미리 렌더(`tools/shakefmt/bgm.py`, DirectMusic 소프트웨어 신스 모델)해서 재생, 곡 선택 규칙은 코드에서 확인
- 그래픽: 폭탄 색 배정, 그리기 순서, 애니메이션 속도, HUD(타이머, 플레이어 패널), 라운드 시작·종료·결과 화면, Hurry, 그림자 등 원본 이미지와 좌표 사용
- 조작: DirectInput 키 코드(이동, 폭탄, 제스처 D 등)
- 규칙: 클라이언트에 있는 수치(이동 속도, 폭탄 시간, 화력·개수 한도, 시작값, 라운드 시간)
- 캐릭터 한글 이름(`shake.exe` 문자열)

범위 밖: 서버에만 있던 로직(아이템 드롭 확률 등, 클라이언트에 없으면 추정으로 남김), 회원·상점·랭킹, 원본 네트워크 프로토콜 호환.

## Approach

- `shake.exe` 정적 분석: capstone 선형 디스어셈블 + 문자열/상수 교차 참조(스크래치 도구). 사운드 매니저(`0x48c0c4`)의 슬롯 표와 재생 함수(`0x4401c0`) 호출 지점에서 역으로 상황을 확정
- Wayback의 당시 매뉴얼·스크린샷(`original/wayback_site/`)으로 교차 확인
- 확인된 사실은 `original/FIDELITY.md`에 근거(주소/URL)와 함께 기록하고, 코드의 RECONSTRUCTED 주석을 근거 있는 값으로 교체

## Steps

1. 효과음 배정 확정 → `presentation.ts`, `audio.ts`(슬롯당 한 소리, 재생 중이면 처음부터 다시)
2. 30 Hz 시뮬레이션으로 교체 (한 번에)
   - `nowMs = floor(tick*1000/30)`로 GetTickCount를 흉내 내고, 원본 비교식(`now-last > 1000/fps`, 퓨즈 `>= 2000`)을 그대로 씀
   - 정수 픽셀 좌표, 속도 5(+1, 최대 10), 걷기 애니 fps `18+4*(speed-5)`, 키를 떼면 다음 애니 진행 때 서기로 전환
   - 이동: 판정 점 3개, 한 점만 막히면 옆으로 미끄러짐, 폭탄은 중심 칸 기준(`+0x1b4` 규칙)
   - 폭탄: 목록 순서로 처리, 불꽃 칸 위 폭탄은 다음 갱신에서 폭발, 불꽃은 폭탄을 통과, 벽돌·아이템에서 멈춤, 불꽃 8프레임(`>66ms`), 폭탄 개수는 불꽃이 끝날 때까지 셈
   - 벽돌: 폭발 즉시 통과 가능, 깨지는 애니(시트별 프레임 수)가 끝나면 숨은 아이템 등장(`rand()%300 < 40`)
   - 사망: anim 20이 한 바퀴 돈 뒤 아이템 흩뿌림과 라운드 판정(마지막으로 죽은 사람이 이김)
   - 라운드 흐름: 대기 1초 → 카운트다운 4초(3·2·1, START 3~4초) → 타이머 150초(첫 틱에 149) → 70초 Hurry → 60초 서든데스(200칸 나선, 200ms마다) → 0초 DRAW, 결과 1.5초 / 최종 5초, 먼저 3승
   - 서버 스냅샷을 매 틱으로
3. 렌더러: 원본 그리기 순서(y 정렬 없음, 그림자 블렌드), 폭탄·불꽃·아이템·벽돌 좌표와 애니, 캐릭터별 폭탄 색, HUD 좌표(타이머, 패널, 아이템 칸, 하단 문구), 카운트다운 `sd.shk`, Hurry 깜박임, 결과 화면(`new_round_e`, `new_game_e`)
4. 배경음 재생: 로비 tbwait11, 대기실 tbwait22, 게임 곡(방장 선택 또는 RANDOM), 카운트다운 끝에 처음부터 재생, 라운드 끝에 정지
5. 조작: 방향 우선순위 UP>DOWN>LEFT>RIGHT, Space 폭탄, LCtrl/Z/D는 특수 아이템용(미구현)
6. 매뉴얼·스크린샷(`original/wayback_site/.../start.jpg`, `win.jpg`)과 비교, 차이 수정
7. 검증과 문서 갱신

## Verification

- `cd tools && python3 -m pytest`, `cd game && npx vitest run && npx tsc --noEmit && npx vite build`
- Playwright 스크린샷을 당시 스크린샷과 나란히 비교
- `original/FIDELITY.md`의 각 항목에 근거가 있고, 남은 추정 항목이 명시되어 있음
