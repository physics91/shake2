# 쉐이크2 복원: 오브젝트 맵

## Goal

지금 에셋 뷰어에서만 볼 수 있는 오브젝트 맵 8개(연습용 `practice.MAP` 제외)를 원본 `shake.exe`대로 플레이 가능하게 만든다.
타일 플래그별 동작, 오브젝트 그림과 애니, 효과음(jump2·warpzone·water·bomb8)까지 포함한다.

## Scope

맵별 셀 플래그로 나눈 기능. A = raw[4] | raw[5]<<16(셀 +8), B = raw[6] | raw[7]<<16(셀 +0xc). 역분석 결과는 `re_work/findings_obj_*.md`에 있다.

| 맵 | 플래그 | 기능(확인) |
|---|---|---|
| desert02 07옐로우라인 | B `0x400`/`0x1000` | 워프 게이트(빨강·노랑, Object_B 0·2) |
| desert01 08점프옐로우, wday02 16캔디 점프 | B `0x20000`/`0x40000`/`0x80000`/`0x100000` | 방향 점프대(Object_B 7..10, 1회 재생) |
| bella02 14점프벨라트릭스 | B `0x800000` | 바라보는 방향 점프대(Object_B 13) |
| block02 12블럭 제너레이터, space02 04스페이스헌터 | B `0x1000000` | 제너레이터: 불꽃이 끝나면 아이템 추첨(Object_B 14) |
| mizar02 02아름다운미자르 | B `0x10000` | 폭발증폭: 화력 = 맵 너비(Object_B 6) |
| snowearth02 06지구전쟁의시작 | A `0x10000`(raw[5] = 1) | 동시폭발지역: 연결된 칸 동시 폭발, bomb8(Object_A 14) |

물·얼음·컨베이어·스위치 타일은 배포된 맵에 없어 범위 밖이다.

- 맵 읽기: 셀 플래그와 오브젝트 목록을 `LevelLayout`에 싣기, 오브젝트 시트(object_a/b/c 중 무엇인지) 확인
- 기능별 시뮬레이션: 발동 조건, 이동, 시간, 폭탄·불꽃·아이템·순간이동·점프와의 상호작용
- 그림: 오브젝트 레이어 0/1/2(`0x4090b8`, `0x409128`, `0x40c183`), 애니 fps
- 효과음 배정, 맵 선택 목록에 추가, 서버의 플레이 가능 맵 목록

범위 밖: 팀전·소환 모드(다음 단계), 계정 정보.

## Approach

- 역분석 먼저: 영역별 서브에이전트(맵 로드·그리기 / 점프대 / 워프·물 / 제너레이터·동시폭발)가 `re_work/findings_obj_*.md`에 근거 주소와 V/I/R를 남김. 핵심 상수는 직접 재확인
- 기능 하나씩 구현(워프 → 점프대 → 제너레이터 → 동시폭발 → 폭발증폭), 테스트 먼저
- 30 Hz, 원본식 시간 비교(`animDue`, 정수 ms), 셀 플래그는 데이터로 전달해 서버와 브라우저가 같은 코드 사용

## Steps

1. 역분석 4건 병렬, 결과 재확인
2. 도구: 맵 JSON에 셀 플래그 내보내기(파이썬 테스트), `LevelLayout`에 플래그·오브젝트
3. 워프 게이트
4. 점프대(방향·바라보는 방향), jump2
5. 제너레이터
6. 동시폭발지역, bomb8
7. 폭발증폭, 서든데스와 오브젝트
8. 그림(오브젝트 레이어), 맵 목록 개방, FIDELITY §10, README
