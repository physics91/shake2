# 쉐이크2 UI/UX만 쓰기: 홈을 시작 흐름으로, 장면 5, 2인 대기실

## Goal

사용자 지시(2026-09-29): "UI/UX는 shake2 UI/UX만 쓴다". 프로젝트 `AGENTS.md`에 규칙을 적고, 보이는 화면을 모두 쉐이크2 화면으로 바꾼다. 홈도 웹 메뉴가 아니라 쉐이크2 시작 흐름(로고 → 로딩 → 로그인)이다.

사용자가 고른 방향:
- 연습 입구: 장면 5 복원. 0311 코드(Go game·Practice·Ranking·Option·Exit, 좌표 일치)에 배경만 쉐이크1 `status.shk`를 쓴다.
- 2인 한 키보드: 원본 GAME ROOM 화면을 로컬로 재사용하고, 서버 목록의 "2인 대전" 줄로 들어간다.
- DOM 보조 요소: 화면에서는 숨기고 화면 낭독기·키보드용으로만 남긴다.
- (기본값, 묻지 않음) 에셋 뷰어는 주소(`#/viewer`)로만 두고 어디에도 링크하지 않는다.

## Scope

보이는 비원본 요소 목록(바꿀 대상):
1. 홈 `#/`: 제목·소개 문단·메뉴 링크 네 개·저작권 문단(`main.ts` `showHome`).
2. 연습·2인 설정 `#/practice`, `#/versus`: 도구 막대, 조작 설명, 캐릭터·맵 선택 격자, 시작 버튼(`main.ts` `showSetup`).
3. 게임 화면(`shell.ts` `gameScreen`): "← 나가기", 제목, 효과음·음악 토글, 조작 설명 문단, 불러오는 중 문구.
4. 시작 화면(`startView.ts`): "← 메뉴", 제목, 조작 설명, 이름·캐릭터 입장 양식, 서버 주소, 오류 줄.
5. 로비·방(`lobbyView.ts`, `online.ts` `RoomView`): 도구 막대, 설명 문단, 자리·팀·준비·시작·채팅 양식, 코드 참가 등.
6. 페이지 바탕(`style.css`): 남색 그라데이션, 둥근 모서리 캔버스, 최대 폭 960 px.
7. 오류 화면(에셋 목록 실패): 예외(원본 그림을 그릴 수 없음).
8. 에셋 뷰어: 예외(개발 도구, 주소로만).

범위 밖: 서버 규칙, 계정 자료(장면 5의 길드·레벨·순위 등은 빈 칸), 새 의존성.

## Approach

- 앱 전체를 하나의 쉐이크2 세션(`OnlineSession`)으로 둔다. `#/`가 그 세션을 띄우고, 예전 주소(`#/online`, `#/practice`, `#/versus`)는 `#/`로 보낸다.
- 흐름: 로고 → 로딩 → 로그인 → 장면 5(My Status) → Go game → 서버 목록 → 로비. 장면 5의 Practice → 연습(장면 9). 연습의 Esc→YES는 서버 목록으로, 150초 시간 초과는 장면 5로(원본 `0x458bc5`, `0x40622b`). 로그인 → 장면 5는 0311과 다름(0311은 서버 목록으로 바로 감): R.
- 장면 5의 그림·입력은 0311 코드 해독(`re_work/findings_scene5.md`, 하위 에이전트)대로. 계정 자료가 없는 칸은 비움.
- 서버 목록에 로컬 줄 "2인 대전"을 원본 줄 모양으로 더함. 두 번 누르면 로컬 대기실(GAME ROOM 그림, 1P·2P 자리, 맵·음악 ◀▶, START, EXIT). 경기가 끝나면 대기실로, EXIT는 서버 목록으로.
- 보이는 것은 캔버스뿐: 페이지는 검정 바탕에 캔버스를 화면에 맞춰 가운데 둔다. 캔버스 밖 DOM은 모두 `sr-only`(낭독기·키보드로는 그대로 씀).
- 새 화면마다 FIDELITY에 줄을 더함(장면 5는 새 절, 로컬 대기실·로컬 줄은 R).

## Flow note

0311 코드에서 장면 5는 게임 서버 접속 뒤에 오고(Go game → 로비, Exit YES → 장면 2), 쉐이크1에서는 로그인 뒤 중심 화면이다. 복원판은 서버 없이 연습할 수 있게 로그인 바로 뒤에 두었다(R). 그래서 서버 목록에서 장면 5로 돌아오는 길은 로고부터 다시 시작하는 것뿐이다. 다른 안: 서버 목록의 로컬 줄에서 서버 없는 장면 5로 들어가기.

## Residual risks (완료 시점)

- 장면 5 배경과 옵션 쪽 패널은 쉐이크1 그림이다(R). 색조 조절, 캐릭터 이름 칸, 레벨 줄은 그리지 않는다(R).
- 숨긴 버튼이 19개로 늘었다. Tab으로 가면 눈에는 보이지 않는다(낭독기 사용자용). 쪽이 맞지 않는 버튼은 알리기만 한다.
- 게임은 저장된 키를 쓴다. 0311에서 취소 뒤 다시 열고 Go로 가면 저장하지 않은 키로 겨루는 경로는 없다(R).
- 2인 조작 키(WASD 등)는 원본 화면에 적을 곳이 없어 낭독기 문구와 README에만 있다.
