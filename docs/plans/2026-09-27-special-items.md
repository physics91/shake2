# 쉐이크2 복원: 특수 아이템

## Goal

개인전에서 벽돌 숨은 아이템의 `r = rand()%300` 중 40~110 구간(특수 아이템, 기본 아이템 0~39보다 많음)을 원본 `shake.exe`대로 구현한다.
아이템 효과, 특수 폭탄, 폭탄 이동(킥·던지기·일렬), 플레이어 상태(점프·순간이동·버로우·보호막·저주), 해당 그림·효과음·아이템 칸 표시까지 포함한다.

## Scope

- 숨은 아이템 추첨표 전체(구간 안의 세부 추첨, "처음 1회만" 규칙)
- 줍기 효과(`0x451100`, 표 `0x451618`)와 아이템 칸 슬롯(`0x4430a0`)
- 폭탄 종류 선택(`0x457ed0`)과 종류별 퓨즈·폭발 모양·불꽃 애니(특수화염 anim 1)
- 폭탄 이동: 킥 굴림, 던지기, 일렬 설치, 원격 기폭(LCtrl)
- 플레이어 상태: 점프(Z), 순간이동, 버로우, 쉐이크 보호막, 물음표 결과(저주 포함), 상태 아이콘
- 조작: LCtrl·Z 추가(원본 키), 2인 한 키보드 모드의 대체 키(R)
- 효과음: bomb2/3/4, jump1/2, warp, item2, switch 등 원본 배정
- 캔디: 줍기로 개수가 생기면 `CANDY_COUNT` 표시(현재 R 행 해소)

범위 밖: 오브젝트 맵(워프·점프대·스위치·물·제너레이터), 팀전·소환 모드(소환캡슐·revival), 계정 정보. 물음표 세부값 중 개인전에서 도달 불가능하거나 해독 불가능한 것은 FIDELITY에 R로 명시하고 제외한다.

## Approach

- 역분석 먼저: 4개 영역(추첨·물음표·줍기 / 폭탄 종류·이동 / 폭발 특수 / 플레이어 상태)을 서브에이전트가 `re_work/shx.py`로 분석하고, 결과는 `re_work/findings_items*.md`에 저장. 핵심 상수(구간 경계, 5000 ms 퓨즈, 핵 반경)는 직접 재확인
- 아이템 종류 번호 = `item.spr` 애니 번호, 폭탄 종류 = `bomb_*.spr` 애니 번호(굴림은 +1)라는 대응을 전 항목에서 확인
- 시뮬레이션은 30 Hz, 모든 시간 비교는 원본식(`animDue`, 정수 ms, 퓨즈 `>=`), 이동은 틱 단위
- 순수 데이터(추첨표, 줍기 효과, 슬롯, 좌표)는 별도 모듈로 분리하고 테스트 먼저 작성

## Steps

1. 역분석 4건 병렬 실행, 결과 저장과 핵심 상수 재확인
2. 입력·프로토콜: `InputFrame`에 LCtrl/Z, 키 배정, 서버 입력 검증(보안 메모)
3. 순수 데이터: 추첨표, 줍기 효과, 아이템 칸 슬롯, 상태 아이콘 좌표
4. 폭탄: 종류, 퓨즈, 폭발 모양(핵·X·파워·직격·더블·TNT), 원격 기폭, 폭탄 스위치, 특수화염
5. 폭탄 이동: 킥, 던지기, 일렬 설치, 캐릭터 애니 12~19
6. 플레이어 상태: 점프, 순간이동, 버로우, 보호막, 저주(느림·초기화·폭탄 금지·반전 등)
7. 그림과 효과음, 아이템 칸, 캔디 개수
8. FIDELITY §9, README, 전체 검증
