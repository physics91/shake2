# 쉐이크2 복원: 게임 중 채팅, 내정보, 시작 화면

## Goal

대기실·방 목록(2026-09-28-room-screens) 다음으로 원본과 아직 다른 화면과 동작을 옮긴다. 대상은 네 가지다.

근거는 `re_work/`에 있다: `findings_gamechat.md`(장면 8 채팅), `findings_myinfo.md`(장면 10), 시작 화면 역분석(진행 중, `findings_startup.md`로 저장 예정).

## Approach

- **프로토콜 4:**
  - C→S `game-chat {text}`와 `typing {on}`.
  - S→C `game-chat {playerId, text}`, 그리고 snapshot에 `typing: id[]`.
  - 서버는 대기·결과 단계의 줄을 버리고 방 전원(보낸 사람 포함)에게 보낸다.
- **클라이언트:**
  - `OnlineGame`에 ChatLine, 말풍선, 도움말, 종료 상자(practiceBox의 "esc" 상자)를 넣는다.
  - 채팅, 상자, 도움말 중에는 입력 변경을 보내지 않고, 닫을 때 다시 보낸다.
- **렌더러:**
  - 네트워크 경로를 연습과 나눈다(`renderNetworkScreen`).
  - 말풍선은 slot 인자를 받게 일반화한다. 연습은 slot 3이다.
- **테스트 먼저:**
  - 프로토콜 파싱.
  - 방 채팅 규칙.
  - Esc/Enter 판단.
  - 말풍선·이름표 위치.
